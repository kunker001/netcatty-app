Netcatty 是用 Kotlin 和 Jetpack Compose 写的原生 Android SSH 客户端，不是桌面版套壳。界面为中文浅色。

一台主机可以同时保持多条 SSH 连接。Catty 对话保存在主机上，断开连接后再打开仍能看到历史。

加密保险库存放标签、主机、端口、用户、密码或私钥，以及笔记。首页只列出正在进行的会话。

终端是交互式 SSH shell，支持双指缩放、闪烁光标和长按选择。当前目录有 docker-compose 时，可以直接启停、重启、暂停容器，并查看日志或进入容器终端。

SFTP 可以浏览远端全部目录，包括 /。内置编辑器能为 yml、conf 等常见文本高亮和格式化，也能把终端定位到当前路径。

端口转发支持本地转发、远程转发和动态 SOCKS5。隧道可以随应用启动。后台通知保持转发，并可以回到隧道列表。

Catty 是可选的主机运维对话。权限分观察、确认和自动。命令在交互式 shell 里执行，步骤可见。API 地址和密钥由你自己填写，兼容 OpenAI 接口。命令黑名单和网络搜索默认关闭，配置后才启用。应用不内置 API 密钥。

这个构建通过 F-Droid 更新，不会自行下载或安装 APK。
